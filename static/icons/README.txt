This directory is for storing icon files for the Crypto Bot project.

Supported icon formats:
- SVG (.svg) - Recommended for scalability
- PNG (.png) - For complex icons
- ICO (.ico) - For favicons
- WebP (.webp) - Modern format

Place your crypto-related icons here such as:
- Navigation icons
- Action buttons
- Status indicators
- Social media icons
- Payment method icons

Files in this directory will be accessible via:
http://localhost:5000/icons/filename.extension
