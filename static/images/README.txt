This directory is for storing image files for the Crypto Bot project.

Supported image formats:
- PNG (.png)
- JPEG/JPG (.jpg, .jpeg)
- GIF (.gif)
- SVG (.svg)
- WebP (.webp)

Place your crypto-related images here such as:
- Crypto currency logos
- Charts and graphs
- Background images
- User avatars
- Bot interface elements

Files in this directory will be accessible via:
http://localhost:5000/images/filename.extension
